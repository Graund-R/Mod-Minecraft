# Download Pocket Mod

Latest JAR: https://github.com/Graund-R/Mod-Minecraft/releases/latest/download/pocketmod.jar

This address stays the same between versions. Save the file, remove the previous Pocket Mod JAR from `mods/`, and put the new JAR there. Minecraft 1.12.2 and Forge are required. The fixed filename is `pocketmod.jar`; the actual version is shown in Minecraft's Mods menu and on the latest GitHub release page.

A successful build of `main` creates a versioned GitHub Release with the JAR, source ZIP and SHA256SUMS. Publication does not require a separate manual tag. A failed build leaves the previous successful download available. Each source update intended for publication must increment `version.txt`.
