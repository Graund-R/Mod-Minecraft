# Создание мира в версии 2.20

Нажать «Изгнанник» на главном экране создания, затем в дополнительных настройках выбрать нужный тип генерации. Можно выбирать в обратном порядке. Эти два выбора независимы: тип мира больше не используется как переключатель сюжетного режима. Возврат из настройки плоского/настраиваемого/модового генератора и изменение размера окна сохраняют выбор режима.

Включение Изгнанника выбирает выживание без ванильного хардкора, поскольку смерть и тотемы регулирует мод. Нажатие ванильной кнопки игрового режима явно выходит из Изгнанника. Сид, структуры, команды, бонусный сундук и строка настроек генератора сохраняются. Нормальная генерация остаётся ответственностью выбранного WorldType; его предсоздающий hook вызывается, тип и JSON не подменяются.

Для конкретного WorldSettings клиент отмечает выбор в синхронизированной слабой карте. Одиночный сервер сохраняет этот же объект; событие создания спавна переносит выбор в WorldSavedData и правило pocketmodExile. Выбор потребляется один раз и не совпадает с другим объектом настроек даже при том же сиде. Если провайдер не вызывает событие спавна, WorldEvent.Load находит отмеченный WorldSettings в полях сервера и переносит его тогда. После этого карта не участвует в повторных загрузках: режим сохранён в данных мира.

Старый тип exile остаётся зарегистрирован для чтения старых сохранений, но скрыт при создании новых. Пересоздание старого мира с таким типом превращает его выбор в обычную генерацию с независимым Изгнанником. Уже созданные миры не регенерируются.

Обесцвечивание в 2.19 и 2.20 не ограничено четвёртой стадией. Сила зависит от процента заражения: первые 10% без фильтра, затем плавная по величине насыщенность от исходной до нуля на 100%. При стандартных порогах стадия 1 начинает примерно с 11% силы, стадия 2 — с 44%, стадия 3 — с 78%, полное заражение — 100%. Смена стадии вручную может сразу изменить силу; между стадиями эффект продолжает меняться с заражением. Особое зрение ослабляет фильтр.

WorldCreationSmoke проверяет настройки, передачу и сохранение без открытия окна или запуска игры. В реальной сборке следует проверить экран создания и используемый генератор отдельно: универсальная совместимость со всеми модами не заявляется.
