# Pocket Mod (Карманный)

Мод для Minecraft 1.12.2 (Forge), одиночная игра.

См. полное ТЗ в обсуждениях.

## Сборка

GitHub Actions автоматически собирает мод при каждом пуше.
Артефакт `pocketmod-jar` появляется во вкладке Actions.

## Версия 0.5

- Данные игрока переживают смерть (мана, уровни способностей, кредит, множитель цен)
- Кредит: ползунок суммы, таймер игрового времени, предупреждения, автосписание, смерть и рост множителя
- Замедление: настоящий пропуск тиков (живые существа + откат снарядов/предметов/TNT)
- Карман: дневной свет, цена входа с кольцами, оплата расширения по стоимости (сдача в ману), безопасный выход, сброс целей мобов
- Телепорт: дальность по уровням, остановка перед стеной, частицы и звук
- Цены способностей приведены к ТЗ
- Команды для тестов: `/manaadd [n]`, `/pocketdebug unlock|expire|mult <x>`
