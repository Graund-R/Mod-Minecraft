# Pocket Mod (Карманный)

Мод для Minecraft 1.12.2 (Forge), одиночная игра. Способности на единой мане: телепорт, невидимость, замедление времени, карман, Спектор, тепловизор, щит, полёт, тело, лутка, мягкое падение, магнит, кровосися, волна. История версий — в [CHANGELOG.md](CHANGELOG.md).

## Структура репозитория

| Путь | Что это |
| --- | --- |
| `src/` | исходники мода (единственный источник кода) |
| `version.txt` | версия мода, например `2.1`; из неё берутся имя jar и версия в меню Mods |
| `optional/journeymap/` | необязательный плагин JourneyMap (метки тотемов), собирается, если удалось скачать API |
| `.github/workflows/build.yml` | сборка |
| `CHANGELOG.md` | что изменилось в каждой версии |

## Сборка

GitHub Actions собирает мод при каждом пуше и пулл-реквесте. Готовый jar — во вкладке **Actions** → нужный запуск → артефакт `pocketmod-<версия>`.

## Как выпустить версию

1. Поменяй `version.txt` (и добавь запись в `CHANGELOG.md`).
2. Закоммить изменения.
3. Создай тег `vX.Y` (на GitHub: **Releases → Draft a new release → Choose a tag → Create new tag**). Тег должен совпадать с `version.txt`, иначе сборка остановится с понятным сообщением.
4. Сборка прикрепит jar к релизу.

## Конфиг

Файл `config/pocketmod.cfg`, в игре: Mods → Pocket Mod → Config или кнопка «Pocket Mod: настройки» в меню паузы.

Значение, уже записанное в файл, перебивает умолчание в коде. Если меняешь умолчание, цену, название категории или ключа, добавь шаг в `ConfigMigrations` и увеличь `ConfigMigrations.CURRENT` (подробнее в комментарии к классу). Перед миграцией создаётся копия `pocketmod.cfg.bak-vN`.
