# Pocket Mod (Карманный)

Мод для Minecraft 1.12.2 (Forge), одиночная игра.

## Сборка

GitHub Actions собирает мод при каждом пуше. Берёт самый новый `pocketmod-v*.zip` из корня репозитория и собирает из него. Артефакт `pocketmod-jar` во вкладке Actions.

## Версия 0.8

- **Невидимость:** мобы, которые уже заметили тебя, теряют цель, если стоят дальше 3 блоков. Проверка при включении и раз в полсекунды.
- **Приманка:** отдельная покупка (250, вкладка «Защита»). Сообщение над хотбаром, если клон не создался.
- **Карман:** телепорт только по внутренним клеткам; фазовый шаг, жемчуг эндера и плод хоруса не выводят за границу. Запрещены призыв, рост растений, костная мука, сон.
- **Замедление:** на уровне 3 колесо до полного нуля (стоп времени), расход 40 маны/сек (`slowZeroDrain`). Плавная виньетка + лёгкая десатурация (отключается `slowDesaturate=false`).
- **Мягкое падение:** вкладка «Движение», цены 200/450. Авто после 4 блоков падения, замедляет и гасит урон. Мана за секунду падения.
- Спектор (удержание X, только выживание), полёт (двойной пробел в воздухе), тепловизор, щит.
- Команда `/pocketdebug info` для проверки уровней и состояния.

## Клавиши (кратко)

| Клавиша | Действие |
| --- | --- |
| G | Телепорт по взгляду / удержание — к последнему тотему |
| Shift+G | Окно тотемов |
| V | Невидимость / удержание — магазин |
| K | Карман |
| Z | Замедление (колесо при удержании) |
| X | Спектор (удержание) |
| Shift+X | Фазовый шаг |
| C | Тепловизор |
| B | Щит |
| Двойной пробел | Полёт |
