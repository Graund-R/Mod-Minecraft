# Pocket Mod (Карманный)

Мод для Minecraft 1.12.2 (Forge), одиночная игра.

## Сборка

GitHub Actions собирает мод при каждом пуше. Артефакт `pocketmod-jar` во вкладке Actions.

## Версия 0.6

- Тотемы: Shift+G открывает окно (создать с названием, список, клик = телепорт, ^ v = порядок, X дважды = удалить)
- Удержание G: быстрый телепорт к последнему тотему в списке
- Маркеры-светлячки над тотемами (клиентские частицы, цвета по порядку, настраиваются)
- Цены: создание, удаление, телепорт (растёт с расстоянием и сменой измерения); улучшения магазина: больше слотов и скидка
- Запасной словарь переводов для окон (если .lang не подхватился)

## Версия 0.5

- Данные переживают смерть; кредит с ползунком и автосписанием; настоящее замедление мира; карман с дневным светом и оплатой расширения по стоимости
- Команды для тестов: `/manaadd [n]`, `/pocketdebug unlock|expire|mult <x>`
